Perguntas frequentes

O ERP Core já está disponível?

Ainda não. O produto está em desenvolvimento. Fale com a FM para saber da disponibilidade.

O ERP Core já é um ERP completo?

Não. O primeiro módulo em construção é o controle de estoque por lote e validade. Os demais módulos serão divulgados conforme ficarem prontos.

O que é FEFO?

É a regra de vender primeiro o que vence primeiro. Ela reduz a perda por vencimento.

Funciona com o Kordena?

São produtos independentes. Qualquer integração futura será anunciada quando existir.

Quanto custa?

Os planos serão divulgados no lançamento.
